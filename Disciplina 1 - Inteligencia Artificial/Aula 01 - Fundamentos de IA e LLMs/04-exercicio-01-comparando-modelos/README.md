# 4. Exercício 01 — Comparando Modelos Diferentes

Agora é sua vez. Vamos rodar o **mesmo prompt** em pelo menos **dois
modelos diferentes** e comparar o comportamento — sem escrever nenhuma
linha de código, só usando as interfaces de chat gratuitas.

## 🎯 Objetivo

Perceber, na prática, que modelos diferentes — mesmo recebendo
exatamente a mesma instrução — não produzem o mesmo resultado. Isso
importa porque, quando você for construir algo de verdade (a partir da
Aula 3), a escolha do modelo é uma decisão de projeto, não um detalhe.

## 🧰 O que você precisa

Conta gratuita em **pelo menos dois** destes serviços:

- [ChatGPT](https://chatgpt.com/) (modelo padrão gratuito)
- [Claude.ai](https://claude.ai/) (modelo padrão gratuito)
- [Gemini](https://gemini.google.com/) (modelo padrão gratuito)

## 🧪 Passo a passo

1. Escolha **um** dos prompts abaixo (ou use os três, se quiser ir além):

   **Prompt A — raciocínio simples**
   ```
   Um trem sai da cidade A às 14h a 80 km/h. Outro trem sai da cidade B,
   a 200 km de distância, às 14h30, na direção de A, a 100 km/h. A que
   horas eles se encontram?
   ```

   **Prompt B — tarefa aberta**
   ```
   Escreva um e-mail educado recusando uma proposta de parceria comercial,
   sem fechar a porta para o futuro.
   ```

   **Prompt C — conhecimento factual de nicho**
   ```
   Quais são as principais diferenças entre a Lei Geral de Proteção de
   Dados (LGPD) brasileira e o GDPR europeu?
   ```

2. Cole **exatamente o mesmo texto**, palavra por palavra, nos dois (ou
   três) modelos escolhidos.
3. Salve print de cada resposta.
4. Preencha a tabela comparativa abaixo.

## 🧪 Perguntas de reflexão

1. Se você tivesse que escolher **um único modelo** para automatizar essa
   tarefa especificamente para a sua empresa, qual escolheria e por quê?
2. A diferença que você observou foi de **qualidade** (um errou, outro
   acertou) ou de **estilo** (ambos corretos, mas escritos diferente)?
3. Isso muda se você tivesse escolhido o Prompt A, B ou C? Modelos
   diferentes tendem a ser mais fortes em raciocínio lógico, escrita ou
   conhecimento factual — o que você observou reforça ou contradiz isso?
